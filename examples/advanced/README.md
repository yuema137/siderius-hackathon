# Advanced baseline variants

These optional local examples use the same task and synthetic data as the
[main walkthrough](../README.md), but different model formats:

- [scikit-learn decision tree](quickstart_classification_sklearn/)
- [Keras MLP](quickstart_classification_keras/)

Both require extra dependencies and use the same published Zenodo record as the
main example; neither is a submission. Follow the instructions in [AGENTS.md](../../AGENTS.md#local-walkthrough-and-advanced-variants).
